# IT3012 - Intelligent Agents - Lab Practicals

## Base Repository (Master Branch)
This branch contains the base code provided for the IT3012 Intelligent Agents lab practicals. 
Please refer to the individual lab branches (e.g., `Lab_01`) to see the completed modifications for each practical session.

### Included Files
- `agent.py`: Agent logic base.
- `grid_game.py`: Standard grid game environment.
- `simulator.py`: Simulator module.
- `visual_grid_game.py`: GUI wrapper and scalable visual environment for the grid game.
- `test_suite.py`: Testing logic.
