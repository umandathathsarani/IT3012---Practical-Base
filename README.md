# IT3012 - Intelligent Agents - Lab Practicals

## Welcome to the IT3012 Lab Practicals Repository!

This repository contains the ongoing coursework and practical implementations for the **IT3012 - Intelligent Agents** module.

### Branching Structure
- **`main`**: The landing branch for this repository.
- **`master`**: Contains the unmodified base code provided for the lab practicals.
- **`Lab_01`**: Contains the completed modifications for Practical 01 (Environment Architecture & Theoretical Evaluation), including the implementation of toxic traps, updated perception subsystems, action executions, and visual renderings according to the PEAS framework.
- *(Future lab sessions will have their own dedicated branches such as `Lab_02`, `Lab_03`, etc.)*

Please switch to the respective branch to view the code and documentation for that specific lab practical!
